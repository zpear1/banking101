Lab Objectives 

Set up a Java project in IntelliJ 

Set up a GitHub account and a repository 

Practice creating local branches and meaningful commit messages 

Practice creating Pull Requests and merging into main 

Project description 

We will develop a simple banking app. There should be two classes in your project: Account and AccountService. The class Account should have the following attributes: 

Account number, unique, automatically assigned, 16 digits 

Type: checking or savings 

Account holder name 

Balance 

Class AccountService should contain the following methods: createAccount, updateAccount, deleteAccount. 

Git and GitHub practice 

Creating a new project in IntelliJ 

From File à New à Project 

In the New Project wizard, select Java  

Give it a name banking101 

Select a location. Aim at the higher-most writable location. This is especially important in Windows as it allows for a shorter file path. 

Build system, select Maven. 

For JDK, select the JDK you want for the project. You can select Download JDK if you don’t have it. 

Expand “Advanced settings” and give GroupId  name “edu.se” 

Check “Add sample code” if you’d like

Initiate a local Git repository  

Follow the instructions in the lecture notes. Stage files, commit, and push to your GitHub. Go to your GitHub in your web browser to confirm that the repository was created. 

Clone a repository 

Add your teammates as contributors to your repository.  

Clone the repository of one of your teammates. Make sure you do it in a new directory.  

Contribute to a repository 

Divide the work on the banking project. Each team member should make their own branch and implement one class or one method. Work in your own local branches. Commit frequently. Push your local branches to remote branches with the same name. 

Create Pull Requests to merge your branches into main. Review each other’s PRs and merge.
